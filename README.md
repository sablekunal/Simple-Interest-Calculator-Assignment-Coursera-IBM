# Simple Interest Calculator

A Bash-based simple interest calculator created for the Coursera IBM Git and GitHub assignment.

## Project Description

This project calculates simple interest using the principal amount, annual rate of interest, and time period supplied by the user.

The formula used is:

```text
Simple Interest = (Principal × Rate × Time) / 100
Total Amount = Principal + Simple Interest
```

## Usage

Make the script executable and run it:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script prompts for:

- Principal amount
- Annual rate of interest (as a percentage)
- Time period (in years)
